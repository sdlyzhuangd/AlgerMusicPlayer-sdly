# AlgerMusicPlayer 编译 Windows EXE 程序步骤

## 一、前置条件

- **Node.js**：建议 18+（项目 DEV.md 说明）
- **依赖**：本项目已通过 `npm install` 安装好依赖（已检测到 `node_modules` 存在）

## 二、编译命令（在项目根目录执行）

### 方式一：直接构建 Windows 安装包（推荐）

```bash
npm run build:win
```

这条命令会执行两步：
1. `npm run build` → `electron-vite build`（编译 TypeScript/Vue 代码到 `out/`）
2. `electron-builder --win --publish never` → 生成 Windows NSIS 安装包

### 方式二：仅生成未打包目录（快速调试）

```bash
npm run build:unpack
```

生成 `dist/win-unpacked/AlgerMusicPlayer.exe`，无需安装，直接运行。

### 方式三：只编译代码不打包

```bash
npm run build
```

只生成编译产物到 `out/` 目录，不生成 exe。

## 三、构建产物位置

构建完成后，生成的 Windows 安装包位于 `dist/` 目录：

```
dist/
├── AlgerMusicPlayer-5.1.0-win-x64.exe    # NSIS 安装包（64 位）
├── AlgerMusicPlayer-5.1.0-win-ia32.exe   # NSIS 安装包（32 位）
├── AlgerMusicPlayer-5.1.0-win-arm64.exe  # NSIS 安装包（ARM64）
└── win-unpacked/
    └── AlgerMusicPlayer.exe              # 未打包版本（可直接运行）
```

## 四、构建配置说明

`package.json` 中的 `build.win` 配置：

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `target` | `nsis` | 生成 NSIS 安装包 |
| `arch` | `x64, ia32, arm64` | 同时构建三种架构 |
| `icon` | `resources/icon.ico` | 应用图标 |
| `artifactName` | `AlgerMusicPlayer-${version}-win-${arch}.${ext}` | 产物命名格式 |
| `requestedExecutionLevel` | `asInvoker` | 以普通权限运行 |

## 五、常见问题

1. **只想要 64 位**：可临时修改 `package.json` 的 `win.target.arch` 为 `["x64"]`，或使用 electron-builder 命令行指定：
   ```bash
   npx electron-builder --win nsis --x64 --publish never
   ```

2. **构建慢**：首次构建会下载 electron 二进制和 NSIS 工具，需要网络；后续构建会缓存。

3. **杀毒软件误报**：未签名的 Electron 应用可能被 Windows Defender 拦截，需添加信任。

4. **自定义安装目录**：该项目已配置 `allowToChangeInstallationDirectory: true`，安装时可选择安装位置。

## 六、快速开始

```bash
# 在项目根目录直接执行
npm run build:win

# 完成后到 dist/ 目录查看生成的 exe 安装包
```

如需进一步调试或中间产物，可先 `npm run build:unpack` 生成 `win-unpacked/AlgerMusicPlayer.exe` 直接运行验证。
